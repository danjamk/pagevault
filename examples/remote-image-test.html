Remote image reference — export test

This page tests how PageVault handles a remote image — one loaded from an absolute https:// URL rather than embedded in the file. The image below is the PageVault wordmark, served from this repository over GitHub's raw host:

What to expect:

  • In the interactive viewer the image loads — the sandbox CSP allows images from any https: host (img-src data: blob: https:).
  • In a PDF export the image is missing. The PDF renderer (#50) aborts every outbound request during the render, so nothing fetched from the network survives into the PDF. Only images inlined as data: URIs render in a PDF.

The gap is deliberate: the interactive view is full fidelity; the PDF trades remote assets for the guarantee that the render never touches the network.
